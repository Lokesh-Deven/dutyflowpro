# Preview Project Workflow

Follow these steps to run and preview the DutyFlow application locally:

## 1. Start Development Server
Start the Next.js development server on port 3000 (with automatic port 9002 forwarding).
```bash
npm run dev
```

## 2. Access Web Preview
Once the server indicates `Ready in ...`, open the preview in your browser:
- Local URL: [http://localhost:3000](http://localhost:3000) (or [http://localhost:9002](http://localhost:9002))
- Dashboard Entry: [http://localhost:3000/dashboard/examinations](http://localhost:3000/dashboard/examinations)
